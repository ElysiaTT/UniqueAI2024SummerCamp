# UniqueAI 2024 Summer Camp - 联创团队 AI 夏令营学习仓库

本仓库用于记录在 **2024 年联创团队 AI 夏令营** 期间的学习成果、实验任务及相关技术文档。本次夏令营的所有实验任务均基于 **AutoDL** 算力平台租用 GPU 实现。

## 📂 项目结构

仓库主要分为以下几个部分：
* **`task1/`**: 第一周任务——逻辑回归手动实现（泰坦尼克号生存预测）。
* **`task2/`**: 第二周任务——深度学习基础（MLP/CNN）及大模型（LLM）部署实验。
* **`ai_painting/`**: AI 绘画入门探索与参考教程。

## 🚀 任务详情与心得

### Task 1: 泰坦尼克号生存预测（手动实现逻辑回归）
本任务不使用深度学习库，从底层逻辑上手动实现了逻辑回归模型。

* **数据预处理**:
    * 删除了对特征影响较小的 `Name` 和 `Ticket` 列，避免干扰归一化。
    * **缺失值处理**: `Age` 采用均值填补，`Embarked` 采用众数填补，`Cabin` 则标记为二进制特征（0 或 1）。
    * **特征工程**: 对 `Sex`、`Pclass` 和 `Embarked` 进行 **One-Hot 编码**，并对 `Age` 和 `Fare` 进行归一化处理。
* **模型构建**: 手动定义了 Sigmoid 函数、损失函数以及梯度下降优化算法。
* **实验结果**: 在训练集上达到了 **61.8%** 的准确率。
* **核心心得**: 学习了 CSV 数据的处理流程，深刻理解了逻辑回归的数学原理及模型调参的重要性。

### Task 2: 深度学习进阶与大模型部署
第二周的学习重点转向了神经网络（MLP/CNN）以及大语言模型的部署实践。

* **大模型（LLM）部署**:
    * **部署模型**: 成功在 AutoDL（Nvidia 4090）上部署了 `Qwen1.5-7B-Chat-GPTQ-Int4`。
    * **技术重点**:
        1.  **库安装**: 解决了 `auto-gptq` 的源码安装及元数据缺失问题。
        2.  **端口映射**: 解决了 AutoDL 远程服务器 Web 界面无法直接打开的问题。通过 **AutoDL SSH 隧道工具** 将 6006 端口映射到本地 `localhost`，成功实现了网页端交互。
* **实验反馈**: 详细记录了模型路径设置、GPTQ 库依赖以及 Web 服务启动过程中的常见报错与解决方法。

### AI 绘画入门
